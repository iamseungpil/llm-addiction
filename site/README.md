# Project page — https://llm-addiction.pages.dev

A single static page (no build step) that summarises the NeurIPS 2026 paper
*Can Large Language Models Develop Gambling Addiction?* with animated charts
and a playable version of the slot machine.

| File | What it holds |
|---|---|
| `index.html` | The page text, section by section, in the paper's order |
| `assets/data.js` | Every number the charts draw, each with the paper table or figure it comes from |
| `assets/main.js` | Chart drawing, scroll animations, the steering dial and the playable slot machine |
| `assets/styles.css` | Layout and theme |
| `assets/img/` | Illustrations generated by `tools/gen_images.py` (decoration only, no data) |
| `assets/fig/` | Paper Figures 1–4, rendered from the camera-ready PDFs |

## Editing the numbers

Change `assets/data.js`, not the chart code. The dose ladders under `steering`
come from the Figure 4 sidecar `paper_data/fig04_causal_battery.json` in the
paper repository; the rest are printed in the body or the appendix tables named
in the comments.

## Preview and deploy

```bash
python3 -m http.server 8787 --directory site      # preview at http://localhost:8787

source ~/.config/secrets/tokens.env
npx wrangler pages deploy site --project-name llm-addiction --branch main
```

`--branch main` publishes to production. Without it the upload goes to a
preview URL and `llm-addiction.pages.dev` stays unchanged.

## Regenerating the illustrations

```bash
source ~/.config/secrets/tokens.env
python3 site/tools/gen_images.py hero          # or: lever_bet lever_goal inside game
```

The script writes PNGs; the page uses JPEG copies
(`sips -s format jpeg -s formatOptions 78 -Z 1100 <name>.png --out <name>.jpg`).
