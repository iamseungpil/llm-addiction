# Project page — https://llm-addiction.pages.dev

A single static page (no build step) for the NeurIPS 2026 paper
*Can Large Language Models Develop Gambling Addiction?*, in a pixel-arcade
style: a hero, three animated scenes, a claims box, resources and BibTeX.

| Scene | What it shows | Data |
|---|---|---|
| Hero | Robot mascot at a slot machine (idle blink, flickering reels) | none |
| 1 · Same machine, two rules | Two **recorded** LLaMA-3.1-8B games replayed side by side (fixed $10 bet vs. model-picked bet), with verbatim excerpts of the model's reasoning and a keyword tag per round ("chasing losses" / "seeing patterns in chance"); replay is 2.2 s per round and pauses while a bubble is hovered; then 10×10 dot grids of the share of 1,600 games per rule that went bankrupt. "Try it yourself" turns both machines into the playable game (30% win, pays 3×). | `assets/games.js`, `PAPER_DATA.slotLlama` |
| 2 · What makes it risky? | One machine steps through the four-rule choice ladder while the bankruptcy meter jumps; then an **illustration** (labelled) of a robot climbing coin stairs toward a goal that keeps moving, with the pooled investment-choice numbers | `PAPER_DATA.choiceLadder`, `PAPER_DATA.goal` |
| 3 · A dial inside the model | Steering dose dial (Gemma / LLaMA, bet-built vs. readout direction), chip stack and dose–response plot | `PAPER_DATA.steering` (Figure 4 sidecar) |

| File | What it holds |
|---|---|
| `index.html` | All page text (about 550 visible words, excluding BibTeX and the collapsed "How we measured it") |
| `assets/data.js` | Every paper number the page draws, each with the table or figure it comes from |
| `assets/games.js` | The two replayed games. Generated by `tools/extract_games.py`; do not edit by hand |
| `assets/main.js` | Replay, free play, dot grids, rule ladder, goal stairs, steering dial, BibTeX copy |
| `assets/styles.css` | Layout and pixel theme (Press Start 2P headings, Inter body) |
| `assets/img/` | Pixel sprites from `tools/gen_images.py` (decoration only, no data) and `og.jpg` |

## The recorded games (`tools/extract_games.py`)

```bash
source ~/.config/secrets/tokens.env        # HF_TOKEN
python3 site/tools/extract_games.py        # rewrites assets/games.js and prints both games
```

It downloads `behavioral/slot_machine/llama_v4_role/final_llama_20260315_062428.json`
from the Hugging Face dataset `llm-addiction-research/llm-addiction` and picks,
deterministically:

1. BASE prompt only (no optional prompt module, so the prompt never mentions goals or patterns);
2. a variable-bet game that goes bankrupt in 6–14 betting rounds and whose fixed-bet twin
   (same prompt, same repetition) stops voluntarily after at least 3 rounds;
3. the highest count of rounds with loss-recovery words (recover, recoup, win back, …)
   plus rounds with pattern/streak words (pattern, streak, due, law of averages);
   ties go to the longer fixed twin, then the lower repetition.

Each round's `tag` comes from the same keyword lists, tested on the shown excerpt and skipped when negated ("no discernible pattern").
Each speech-bubble quote is at most 20 consecutive words of the model's own response,
with an ellipsis at every cut; the script asserts each one is a verbatim substring.
It also prints the arm totals (7 and 1,157 bankruptcies of 1,600), which match the
0.44% and 72.31% in the paper.

## Editing the numbers

Change `assets/data.js`, not the drawing code. The steering ladders come from the
Figure 4 sidecar `paper_data/fig04_causal_battery.json` in the paper repository.
Matched-cap numbers are deliberately not on the page (they are being revised).

## Sprites and share card (`tools/gen_images.py`)

```bash
source ~/.config/secrets/tokens.env        # OPENAI_API_KEY
python3 site/tools/gen_images.py            # robot slot chip coins flag dial (gpt-image-2, transparent PNG)
python3 site/tools/gen_images.py --process-only robot   # redo the pixel pass on cached raws
python3 site/tools/gen_images.py --og       # rebuild assets/img/og.jpg (1200x630, ImageMagick + Menlo)
```

Raw 1024px images are cached in `$SPRITE_RAW_DIR` (default `$TMPDIR/llm-addiction-sprites`),
outside the deployed folder. The pixel pass crops, shrinks with an area filter, snaps to a
small palette and a hard alpha edge, and writes tiny PNGs (1–8 KB) that the page shows with
`image-rendering: pixelated`. `robot-blink.png` is derived from `robot.png` by painting over the
eyes. The reel overlay positions in `styles.css` and the eye boxes in `blink_frame()` were
measured on the current sprites: re-check them if you regenerate `slot` or `robot`.

## Preview and deploy

```bash
python3 -m http.server 8788 --directory site      # preview at http://localhost:8788
```

Deployment is automatic: every push to `main` that touches `site/` runs
`.github/workflows/deploy-site.yml`, which checks the page scripts and publishes
to `llm-addiction.pages.dev` (repository secrets `CLOUDFLARE_API_TOKEN` and
`CLOUDFLARE_ACCOUNT_ID`). It can also be run by hand from the Actions tab.

To deploy manually instead:

```bash
source ~/.config/secrets/tokens.env
npx wrangler pages deploy site --project-name llm-addiction --branch main
```

`--branch main` publishes to production. Without it the upload goes to a
preview URL and `llm-addiction.pages.dev` stays unchanged.
